# To Do App

A task management web application built with HTML, CSS, and JavaScript. This project allows users to organize their daily tasks, categorize them by different areas of life, manage deadlines, and view tasks in a calendar layout.

## 📌 Project Overview

The **To Do App** was created as a school assignment to practice front-end web development and JavaScript functionality. The application helps users keep track of tasks by allowing them to create, edit, delete, and complete tasks while organizing them into categories such as Personal and Work.

The application also supports task times and includes a calendar view to help users visualize and manage their schedules.

## ✨ Features

- **Add Tasks:** Create new tasks using a form.
- **Edit Tasks:** Update existing task information.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Mark Tasks as Complete:** Mark finished tasks and visually distinguish them from incomplete tasks.
- **Task Categories:** Organize tasks by areas of life, such as Personal and Work.
- **Task Times:** Assign times to tasks to help manage your schedule.
- **Calendar View:** View tasks in a calendar layout.
- **Filter Tasks:** Filter tasks to make it easier to find and organize relevant items.
- **Empty State:** Display an appropriate interface when there are no tasks to show.
- **Form Handling:** Prevent the page from refreshing when a task form is submitted.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and its content.
- **CSS3** — Styles the application, including task cards and completed-task appearances.
- **JavaScript** — Handles task functionality, form submissions, task interactions, and dynamic webpage updates.

2. Open the project folder on your computer.
3. Open `todo.html` in your web browser to view the application.

### HTML, CSS, and JavaScript

- How to structure a webpage using HTML and connect it to external CSS and JavaScript files.

- How to add and remove a CSS class, such as a `completed` class, to change the appearance of a task card.
